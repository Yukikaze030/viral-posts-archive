## 1.39.4 补采首楼

首楼从帖子顶部的独立区域读取，回复楼号从楼层标签读取。已用真实导出核对《A!大胆的往上A!》的首楼正文、配图和行内表情。升级后重新加载扩展并刷新帖子，等首楼显示再导出，已有缓存可继续使用。

## 1.39.3 补抓表情图源

支持从图片属性、CSS 背景和伪元素读取表情源。旧的离线导出若没有任何图源，需要重新加载目标楼层后再导出。

## 1.39.2 表情采集

正文按顺序保存文字、Unicode 表情和贴吧行内表情图。HTML 离线内嵌可用表情图，Markdown 保留行内位置和链接，JSON schemaVersion 2 在每楼增加 parts。原缓存仍可读；要补旧缓存中没有的表情，需要让对应楼层重新出现在页面上再导出。1.39.3 已通过实际导出验证。

在浏览器中逐步滚动贴吧帖子，累积保存楼主主楼文字和配图，导出离线 HTML、Markdown 及下载失败清单。基于 SingleFile 1.39.0，当前版本 **1.39.4**；非官方版本。

## 安装与使用

1. 下载并解压插件 ZIP，在 Edge 打开 `edge://extensions/`，开启开发人员模式。
2. 暂时关闭原 SingleFile，点击“加载解压缩的扩展”，选择解压后的 `singlefile-tieba` 文件夹（含 manifest.json）。
3. 刷新贴吧帖子，选择“只看楼主”、正序，回到顶部。右下角点击“开始／继续滚动”，停止后点击“导出／重试图片”。允许浏览器连续下载三个文件。

离线图片嵌入 HTML；Markdown 的图片使用在线地址。JSON 保存楼层、图片地址和失败原因。失败后可重试，不必重新滚动；缓存保留在本浏览器的贴吧站点 IndexedDB，清理站点数据会丢失缓存。更新时在扩展管理页重新加载后刷新帖子，不要先删除扩展或清空缓存。

## 当前功能与限制

- 楼层累积、按帖子恢复、图片逐张下载与失败记录；不转录图片文字，不上传采集内容。
- 只支持当前新版贴吧页面里的楼主主楼，不展开楼中楼，不下载视频或音频。不同页面结构仍可能需要适配。
- 到底停止不等于全帖完整：未加载、被隐藏、被删除的内容不能保证采集到。JSON 的 `complete:false` 表示未作完整性认证。
- 保存网页提供的图片地址，不承诺一定是最高分辨率原图。超长帖子可能遇到浏览器内存和缓存容量限制。
- 沿用原 SingleFile 的较广站点权限；新增采集仅在贴吧帖子触发，新增后台图片下载限定贴吧图片域名。导出材料可能含原帖中的个人信息，请自行检查后分享。

## 实测与检查

2026-11-20，用户在 Edge 对《给大伙讲讲我和初恋的故事》测试：采集 255 条楼层记录、70 张配图，失败 0。已逐张解码检查导出 HTML 的 70 张图片。2026-11-21，“英语老师”另采集 234 条楼层、107 张配图，失败 0；107 张图片同样逐张解码通过。1.39.1 在这两个真实样本的基础上转为稳定版，本次不改变采集逻辑与缓存格式。这些结果不代表所有帖子均完整。

新增后台的本地测试：在本目录运行 `node test-background.cjs`。检查专用连接下载返回、拒绝非图片域名与非贴吧发起页面；不代替真实网络验收。
