## 安装

1. Edge 打开 `edge://extensions/`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择本文件所在目录，即 `你解压后的 tools\singlefile-tieba 文件夹`。
3. 测试时暂时关闭官方 SingleFile，避免两份同时响应相同快捷键、自动保存。测试完可以随时切回。
4. 刷新已经打开的贴吧帖子。右下角出现“贴吧长帖采集 · 稳定版”。这个新增面板与 SingleFile 工具栏按钮分别使用。

## 使用

1. 切换“只看楼主”和正序，回到帖子顶部。
2. 点击“开始／继续滚动”。等待页面逐步向下滚动；保留该标签页，避免切换帖子或同时开两个同帖采集页。
3. 到底后程序会等待多轮无增长才停止。你仍需检查末尾是否到达；网络卡顿也可能造成停止，可再次继续。
4. 点击“导出／重试图片”。会依次下载 HTML、Markdown、JSON 三份文件。若浏览器拦截多个文件下载，允许本页多文件下载后再次导出。
5. 断网打开 HTML，检查第 67 楼等已知配图。Markdown 保留在线图片地址，HTML 才是包含离线图片的版本。
6. JSON 记录楼层、帖子内 ID、配图地址与失败原因；若有失败，联网后再次点击导出会重试未成功的图片。

新增采集不会转录图中文字，不自动发布或上传。缓存放在本浏览器贴吧站点的 IndexedDB，按帖子 ID 区分；刷新后可恢复。清理贴吧站点数据会清除缓存，浏览器崩溃前尚未完成的事务可能丢失。请及时导出。

## 边界

- 当前只适配本项目样本中的新版 `.pb-comment-item`、`.comment-content` 和 `.image-card-wrapper` 结构，仅采集标记为楼主的主楼，不采集楼中楼、视频、音频。
- 只保存实际观察到的内容；不承诺恢复删帖、隐藏内容或尚未加载的楼层。导出记录固定 `complete:false`，避免误认为已经完整核验。
- 按楼层累积图片，保留带参数的图片请求地址，按去掉查询参数的地址去重；下载失败不会当作成功。源地址由网页提供，不保证都是最高分辨率原图。
- 图片逐张下载，超时 25 秒；单图超过 30 MB 拒绝，过大的整帖导出可能受浏览器内存、缓存配额限制。
- 新增内容不修改网页原楼层；目前没有自动打开“只看楼主”、自动展开楼中楼或跨帖子跳转功能。
